# 画像圧縮ツール (Local Image Compressor)

ブラウザの Canvas API を利用して、画像の圧縮・リサイズ・フォーマット変換をすべてローカル環境（クライアントサイド）で行うWebツールです。外部サーバーへの画像アップロードが一切発生しないため、機密性の高い画像や商品画像なども安心して処理できます。

## 主な機能

* **多彩な画像読み込み方法**
  * ファイル選択ダイアログ、ドラッグ＆ドロップ、クリップボードからの直接ペースト（`Ctrl+V` / `Cmd+V`）に対応
* **ビフォー・アフターのリアルタイム画質比較**
  * スライダーを左右に動かすことで、圧縮前の元画像と圧縮後の画像を同一画面上で重ねて比較可能（透過画像にも対応した市松模様背景を採用）
* **フォーマット変換と画質調整**
  * **出力形式**: JPEG / WebP / PNG（可逆圧縮）
  * **画質設定**: 1〜100 の範囲で細かく調整可能（JPEG変換時は透過部分を白背景で自動補完）
* **長辺基準のリサイズ機能**
  * 「元のまま」のほか、長辺 `2000px` / `1600px` / `1200px` / `800px` / `600px` のプリセットからアスペクト比を維持して縮小可能
* **ファイルサイズ・削減率の即時表示**
  * 圧縮前後のファイル容量（KB / MB）、解像度（幅×高さ）、および削減率（%）をリアルタイムに算出
* **レスポンシブ＆ダークモード対応**
  * PC・スマートフォンの両方で見やすいレイアウトと、OS設定に連動したライト／ダークテーマに対応

## 使い方

1. `index.html`（または `画像圧縮ツール.html`）をブラウザで開きます。
2. 圧縮したい画像を画面にドロップするか、「画像を選ぶ」ボタン、または貼り付け操作で読み込みます。
3. 「形式」「画質」「長辺のサイズ」を好みに合わせて調整し、プレビューのスライダーで劣化具合を確認します。
4. 削減率と画質に問題がなければ「**ダウンロード**」ボタンから保存します（元のファイル名に `-min` が付与されます）。

> **※ ダウンロード機能に関する注意**
> 現在のコードは Claude のアーティファクト環境（`claude.use("downloads")`）向けにダウンロード処理が実装されています。通常のWebブラウザ（Chrome / Edge 等）単体や GitHub Pages で直接保存できるようにする場合は、標準の `<a download>` を使ったダウンロード処理への書き換えが必要です。

## 技術スタック

* HTML5 / CSS3（CSS Variables, Flexbox, Grid, `clip-path`）
* Vanilla JavaScript（Canvas API, Blob / Object URL, Clipboard API）
* 外部ライブラリ・ビルド環境不要の単一HTMLファイル構成
